# BOBBY Deriv connection setup\n\nThe intended voice flow is: say “connect to my Deriv” → BOBBY opens the Deriv setup panel → explains the App ID and token fields → verifies the account → reports account ID, currency and balance. Credentials must be entered into the app, never into chat.\n\n1. Sign in to Deriv directly.\n2. Create an API token with minimum scopes. Start with Read. Add Trade only when demo trading is implemented and explicitly wanted.\n3. Register an application in the Deriv API dashboard and copy its numeric App ID.\n4. Enter App ID and token in BOBBY's secure Deriv panel.\n5. Press Verify connection.\n6. Delete credentials in BOBBY and revoke the token in Deriv if the phone is lost.\n\nCurrent code adds an Android Keystore AES-GCM secret vault and a Deriv v3 WebSocket authorize adapter. The adapter verifies identity and balance only; it does not place trades. The setup screen and natural-language routing still need wiring. The newer Deriv REST/OTP API flow also remains a separate future integration.\n\nNever provide your Deriv password, payment credentials, seed phrase, or unrestricted Admin token.\n
